1. git init -b main
   Initializes a new local Git repository in the current folder and sets 'main' as the default branch.

2. git config user.name "IshikaSharma04"
   Sets my GitHub username as the author for commits in this repository.

3. git config user.email "ishika.24bcs10352@sst.scaler.com"
   Configures my student email address associated with my GitHub account.

4. git status
   Checks the current status of the repository, showing untracked, staged, or modified files.

5. git add index.html about.html
   Stages index.html and about.html so they are ready to be included in the next commit.

6. git commit -m "Initial commit: Add index.html and about.html"
   Saves the staged files to the repository history with an initial commit message.

7. git branch feature
   Creates a new branch named 'feature' from the current commit.

8. git checkout feature
   Switches the working directory to the 'feature' branch.

9. git checkout main
   Switches back to the 'main' branch from the feature branch.

10. git merge --no-ff feature -m "Merge branch 'feature' into main"
    Merges the changes from the 'feature' branch into the 'main' branch with an explicit merge commit.

11. git log --oneline --graph --all
    Shows the commit history as a graph with one-line summaries to display all commits and branch activity.

12. git reset HEAD~1
    Undoes the last commit by moving HEAD back by one commit, keeping the changes in the working directory as unstaged.

13. git remote add origin git@github.com:IshikaSharma04/bits-software-development.git
    Connects the local repository to my public GitHub repository.

14. git push -u origin main
    Pushes the local commits on the main branch to GitHub and sets up tracking.

15. git push origin feature
    Pushes the feature branch to GitHub so the branch history is visible on GitHub.
